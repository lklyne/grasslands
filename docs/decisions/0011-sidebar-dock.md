# 0011 Sidebar dock

Date: 2026-10-16. Status: accepted.

The window body is a GPUI Kit `DockArea` (`gpui_kit::component::dock`) wearing the stock `DockSkin`, with three panels: spaces (`WorkspaceList`), agents (`AgentList`, split out of the workspace list) and files (`FileTree`). The human asked for the agents section as its own panel, drag-and-drop rearranging, and the Kit's built-in look and theme colors so themes switch cleanly.

- **One dock for the window** (`workspace::dock`). The main area (terminal area or editor) is a title-bar-less `MainPanel` in the center; the sidebar panels start in the left dock (260px, collapsible from the skin's toggle). A panel dropped toward the main area's edge splits the center beside it, so panels can sit right of (or below) the editor. The main panel has no title bar, so it can't be dragged itself.
- **Terminals hide during a drag.** The Ghostty views are native views above GPUI and would cover the drop indicator, so `Workspace::render` hides the terminal area while `cx.has_active_drag()` and shows it again on drop. GPUI doesn't expose the active drag's type and the Kit's dock drag is internal, so the app's own drags opt out instead: file-row and pane-header `on_drag` constructors call `workspace::keep_terminals_during_drag`, since their drop targets aren't under the terminals and blanking them mid-drag looked broken.
- **Built-in chrome.** The skin draws each panel's title bar. Panel controls are `toolbar_buttons` (spaces: New Workspace; agents: the Grouped/Priority toggle; files: new file, new folder, refresh) and the skin's ⋯ menu (spaces: New Workspace, New Worktree…, Command Palette…). The old herdr-style "spaces" label row, the "new"/"menu" footer and the files header are gone. Panel titles are `text_sm`. Count badges are `Tag::danger()` / `Tag::info()`. Status colors use the theme's semantic `danger`/`warning`/`info`/`success` instead of `red`/`yellow`/`cyan`/`green`.
- **Rows unchanged.** Workspace and agent rows keep herdr's monospace layout and rules (0009).
- **Panels can't be closed or zoomed.** `closable` is false so a panel can't be lost, and zoom is withheld in a sidebar this narrow.
- **Persistence.** On every `DockEvent::LayoutChanged`, debounced 500 ms, the layout is written to `~/Library/Application Support/grasslands/dock-layout[-<HERDR_SESSION>].json`, so a dev session never overwrites the real one. On launch it loads if the version matches and all four panels come back; otherwise the default (main in the center; spaces / agents / files stacked in the left dock) is used. Saved panels are rebuilt through `register_panel` closures that hand back the live entities.
- **Script hooks.** `RT_SIDEBAR_SCRIPT` still drives both panels; `toggle-agents` and `menu` are gone with the controls they clicked.
- **One tab strip** (2026-10-16). The titlebar no longer holds tabs; it shows the focused space's name. The main area's strip (`workspace::main_area`) holds the space's herdr tabs, then the open files, then +. `TerminalArea::render_tab_bar` draws it with the file tabs passed in; clicking a herdr tab dispatches `ShowHerdr`. The strip no longer repeats the space name.
